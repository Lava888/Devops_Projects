# 🏗️ Terraform Infrastructure as Code

Infrastructure provisioning using Terraform across cloud providers.

## 📁 Directory Structure

```
terraform/
├── aws/                # AWS infrastructure
├── gcp/                # Google Cloud infrastructure
├── modules/            # Reusable modules
└── README.md
```

## 🚀 Quick Start

```bash
cd terraform/aws
terraform init
terraform plan
terraform apply
```

## 📖 Documentation

Each cloud provider folder has detailed README with setup instructions.
